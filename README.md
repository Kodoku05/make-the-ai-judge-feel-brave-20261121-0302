This entry writes a short, steadying piece of text for the make.fun competition. Its evening scene gives the reader a quiet place to pause before beginning again.

### How it works

Run `node main.ts` with Node 22. The program writes the same UTF-8 text to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another output directory.
